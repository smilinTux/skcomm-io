Core Principles

Transport Agnostic

Message format is universal. Transports are plugins. Swap them at will.

Redundancy by Default

Multiple transports simultaneously. Automatic failover. Never offline.

End-to-End Encrypted

PGP-signed messages. Transport never sees plaintext. Perfect forward secrecy.

Identity Verified

PGP keypairs. Signature verification. No spoofing. No impersonation.

Works Offline

Queues messages when offline. Delivers when connection returns. Handle network partitions gracefully.

Architecture

ABC Pattern

Agent Bus Communication — A unified interface that treats all transports as interchangeable plugins. Each message is wrapped in a universal format, encrypted with PGP, then distributed across all active channels simultaneously.

Get Started

# Install SKComm

$ pip install skcomm


# Initialize your identity

$ skcomm init


# Discover peers on the network

$ skcomm discover


# Send your first message

$ skcomm send --to lumina "Hello from the sovereign mesh"
